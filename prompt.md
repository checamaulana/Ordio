# Rules

— Implement the `docs/PRD.md`
— Follow the phases and checklist in `docs/IMPLEMENTATION_PLAN.md`
— Match the architecture and data flow defined in `docs/APP_FLOW.md`
— Use the tech stack specified in `docs/TECH_STACK.md` — Laravel 11, Inertia.js 2.x, React 18, TypeScript, Tailwind CSS, shadcn/ui, MySQL, Bun
— Follow frontend patterns, design system, and component structure from `docs/FRONTEND_GUIDELINES.md`
— Follow backend patterns, models, controllers, and migrations from `docs/BACKEND_STRUCTURE.md`
— Work in commits — commit after each meaningful change with a descriptive message
— Read `docs/progress.txt` at the start of every session to know the current state
— Update `docs/progress.txt` after completing any feature or task
— Review `docs/lessons.md` at session start to avoid repeating past mistakes
— Update `docs/lessons.md` after every correction or new learning
— Use UI prototype for design from `design/`
— Check all of your work with the agent—browser skill
